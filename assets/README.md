# assets

本目录存放从 ProcessOn 导出的 PNG 图（简历/作品说明用）。

操作步骤见 `design/ProcessOn使用说明.md`：
1. 打开 ProcessOn → 导入 `design/` 下的 `.drawio` 文件
2. 微调后 → 导出 PNG → 保存到本目录

推荐导出：
- `assets/门店画像-线框图.png`
- `assets/标签库后台-线框图.png`
- `assets/潜力打分流程.png`
- `assets/系统架构图.png`

（默认不入库，如需提交可在 `.gitignore` 去掉 `assets/*.png`。）
