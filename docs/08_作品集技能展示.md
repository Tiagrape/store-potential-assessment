## 4. 面试高频追问与准备

| 问题 | 建议回答要点 |
| --- | --- |
| 打分模型权重怎么定的？ | 业务直觉定初值（交易最重30%）→ 数据校准定终值（600万分布重拟合）；当前为示例值 |
| 为什么是 5 个维度？ | 覆盖"盘面/承载/成交/机会/触达"完整业务面，框架定稿、数值可调 |
| 校准和排名什么关系？ | 加权算绝对分，分位校准把它换算成全库位次；不改排序只换标尺 |
| AI 标签怎么保证不胡说？ | 提示词强制引用证据、固定 JSON 输出、数据不足降置信度 |
| Knowhow 是什么？ | 把行业经验编码成可引用的知识（K1-K4），让打分/标签/AI 有据可依 |
| 字段和标签什么区别？ | 字段是数据，标签是结论；一个标签由 1 或多个字段算出 |
| 计算主键为什么重要？ | 决定标签/分数是否因企业而异：`store_id` 一致，`store_id+企业` 因人而异 |
| Skill 和 Agent 什么关系？ | Skill 是标准功能模块（工具），Agent 编排调用它们；Agent 动脑，Skill 动手 |
| 为什么企业视角不提供切换？ | 客户按登录身份定视角，天然隔离；管理员代看是后台产品迭代 |
| 哪些要真实数据校准？ | K2 基准、公式参数、分层阈值、风险系数等；结构/口径/公式框架已定稿 |

## 5. 简历写法建议（这段经历）

> **门店售卖潜力评估方案设计**（类目体系后续）：
> 基于 600 万门店与多租户经营数据，设计"企业-门店"两层口径与 5 维潜力打分模型（加权合成+分位校准+风险扣分），沉淀行业 Knowhow 知识库与可复用 Skill 模块，产出两套可交互原型与 PRD、流程图、原型图，明确待真实数据校准的参数清单，推动方案进入研发评审。
