## 2. 核心用例（详细）

### UC-01 查看单店潜力画像
- **主角色**：销售 / 企业运营
- **前置**：登录（企业视角 = 当前登录企业）
- **主流程**：
  1. 进入门店画像页
  2. 搜索/筛选定位目标门店
  3. 查看潜力分可视化（final / 分层 / 分位 / 五维雷达图 / Top3 驱动）
  4. 查看企业视角概览 + 核心指标
  5. 查看 AI 画像洞察 + 推荐动作
  6. 查看标签、竞品、库存资产、协议
- **异常**：数据不足时，画像显示"数据不足"降级提示，不虚构

### UC-02 模拟圈选高潜门店
- **主角色**：企业运营
- **主流程**：
  1. 在后台选择圈选标签（如"高潜力待突破门店"）
  2. 点击"运行模拟圈选"
  3. 查看预估命中门店数 / 可转化 GMV / 规则可信度
  4. 查看命中规模分布 + 样本预览
  5. 确认 → 正式圈选，生成推送名单
- **异常**：真实数据未接入时，仅展示演示值并标注

### UC-03 配置打分模型权重
- **主角色**：平台管理员
- **主流程**：
  1. 进入后台"打分模型配置"
  2. 调整 5 维权重（实时合计须 =100%）
  3. 调整分层阈值 / 查看风险扣分规则
  4. 选 Demo 门店"模拟跑分"看分数变化
  5. 保存（校验权重和）→ 发布新版本
- **业务规则**：权重合计必须 =100%，否则提示/拒绝；默认权重 15/15/30/25/15

### UC-04 管理标签（定义→审批→发布）
- **主角色**：平台管理员 + 审批人
- **主流程**：
  1. 定义标签口径 / 规则 / AI提示词
  2. 走审批流（需求发起→数据口径评审→业务审批）
  3. 发布，进入灰度
  4. 监控覆盖与质量，异常告警
  5. 效果回溯，必要时回滚
