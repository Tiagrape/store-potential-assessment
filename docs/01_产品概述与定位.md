# 01 产品概述与定位

## 1. 背景与问题

- **行业背景**：快消 B2B 渠道中，品牌商/经销商需要快速找到"值得投入"的线下门店。但传统铺货靠销售经验判断，覆盖面有限、判断标准不一。
- **数据基础**：公司（CRM SaaS 平台）已沉淀 **600 万门店**及每个门店在各租户企业的经营数据（订单、拜访、库存、竞品、协议等）。
- **核心矛盾**：数据量大但未变成"决策依据"。业务想知道——**某家企业到底该优先攻坚哪些门店**。

## 2. 产品定位

> 一套**面向企业-门店关系的售卖潜力评估体系**：把 600 万门店清洗、打分、打标签，识别每个企业对每家的高潜力门店，推送企业以提升市场覆盖率。

**关键洞察**：潜力不是"门店的属性"，而是"**某企业 × 某门店**"这对关系。同一家店，对饮料企业可能是高潜，对家清企业可能是另一个结论。

## 3. 目标用户与核心价值

| 角色 | 需求 | 产品价值 |
| --- | --- | --- |
| 品牌商/经销商 | 找到值得投入的门店 | 高潜门店推荐、品类/品牌切入建议 |
| 销售/业务员 | 拜访前知道去哪、谈什么 | 门店画像、推荐动作、话术 |
| 运营/管理者 | 覆盖率提升、效果可量化 | 圈选、效果回溯、看板 |

## 4. 核心概念（贯穿全产品）

- **两层分析对象**：门店全局层（`store_id`）｜企业-门店机会层（`tenant_enterprise_id + store_id`）
- **标签**：普通标签（规则可算）+ AI 高阶标签（AI 推理）
- **潜力评分**：5 维加权 + 校准 + 风险扣分（详见 docs/07）
- **Knowhow**：行业经验的结构化沉淀（指标口径/基准/场景/动作）
- **Skill**：可复用的标准化功能模块

## 5. 竞品参考（借鉴不复制）

- 零售数据：舟谱数据（门店经营分析）、尼尔森 IQ / 凯度（品类角色、渗透、竞品对标）
- 商家分层：有赞 / 微盟（商家分层、营销响应）、抖音（兴趣识别、策略推荐）
- 数据中台：百炼 / 棱镜（指标治理、标签工程化）

## 6. 一句话价值主张

> 让每一家门店的经营数据，变成"该推给谁、推什么、怎么推"的决策依据。
