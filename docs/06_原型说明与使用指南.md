# 06 原型说明与使用指南

## 1. 原型清单

| 原型 | 文件 | 定位 |
| --- | --- | --- |
| 门店画像 v2 | `prototype/门店画像_v2.html` | 前台：单店潜力画像（可交互高保真） |
| 标签库管理后台 v2 | `prototype/标签库管理后台_v2.html` | 后台：标签治理 + 打分模型 + Knowhow + Skill |

两个均为**自包含单页**（数据内嵌 JS，无外部 CDN/依赖），**浏览器双击即可打开**。

## 2. 门店画像 v2 使用说明

### 打开
浏览器打开 `prototype/门店画像_v2.html`

### 界面与交互
| 区域 | 操作 | 内容 |
| --- | --- | --- |
| 顶部统计 | 查看 | 门店数 / 高潜数 / 平均潜力分 / 均单店GMV / 缺货数 / 业态数 |
| 左侧门店池 | 搜索 / 筛选 | 搜门店名/城市/标签；按城市层级/业态/潜力分层筛选 |
| 门店卡片 | 点击 | 切换当前选中门店 |
| 右侧详情 | 查看 | 潜力分可视化 + 雷达图 + 画像 + 标签 + 竞品等 |

### 潜力分可视化（v2 核心新增）
- **final_score 大字** + 分层色标（高潜/成长/基础/低效）+ 分位
- **五维雷达图**（SVG）：基础盘面/资产承载/交易表现/竞争机会/触达可转化
- **Top3 驱动维度**：解释分数来源
- **风险扣分红面板**：命中项 + 扣分数（如缺货 -8）
- **分数拆解 explain**：维度→指标→证据字段三级（S001/S003/S010 为完整版）

## 3. 标签库管理后台 v2 使用说明

### 打开
浏览器打开 `prototype/标签库管理后台_v2.html`

### 界面与导航
左侧导航四页（+ 移动端顶栏）：
- **① 标签总览与分析**：标签列表/筛选、标签详情（口径/血缘/规则/提示词/版本/审批/效果回溯）、覆盖预估与模拟圈选、质量监控
- **② 打分模型配置**：维度权重编辑器（滑杆/输入，实时合计=100%）、二级指标表（公式+Knowhow引用）、分层阈值、风险扣分规则、**模拟跑分**（下拉选 Demo 门店即时重算）
- **③ Knowhow 知识库**：K1 口径 / K2 基准 / K3 场景 / K4 动作 四层浏览 + 搜索
- **④ Skill 注册与调用**：5 个 Skill 的输入/输出 Schema、执行步骤、降级策略、运行记录

### 演示重点
- **模拟跑分**：②打分模型配置 → 下拉选 S001 → 看 raw→校准→final→分层（与文档 07 一致）
- **权重可调**：把"交易表现"权重从 30% 拉到 10%，看分数怎么变（演示权重是配置，可调）

## 4. 演示推荐顺序

1. 画像页：看整体（门店池 → 高潜店雷达图 → Top3 驱动）
2. 画像页：看解释（风险扣分、三级拆解）
3. 后台：看标签治理（血缘/规则/审批）
4. 后台：打分模型配置 → 模拟跑分（验证可复算）
5. 后台：Knowhow / Skill 模块

## 5. 边界说明

- 当前数据为**内置 10 家 Demo 门店样例**，非真实数据
- 所有分数/权重/阈值为**示例值**，待真实数据校准
- 企业视角为**每店一个企业**的演示口径；真实产品中客户按登录身份定视角
