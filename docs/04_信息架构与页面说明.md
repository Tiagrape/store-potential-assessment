## 2. 页面说明

### 2.1 门店画像页（前台 · 高保真原型：`prototype/门店画像_v2.html`）
- **用途**：向企业/销售展示单店在"本企业视角"下的潜力与画像
- **核心设计**：左侧门店池 + 右侧详情，右上角潜力分可视化 + 雷达图
- **交互**：搜索、筛选、点击切换门店；雷达图内联 SVG，无外部依赖
- **关键元素**：
  - 潜力分大字 + 分层色标 + 分位
  - 五维雷达图（一眼看出强弱）
  - Top3 驱动（解释"为什么是这个分"）
  - AI 洞察区分"事实依据/经营判断/推荐动作"

### 2.2 标签库管理后台（后台 · 高保真原型：`prototype/标签库管理后台_v2.html`）
- **用途**：平台管理员治理标签、配置打分模型、沉淀 Knowhow、注册 Skill
- **核心设计**：左侧导航 + 右侧内容区，四页 Tab（标签/打分/Knowhow/Skill）
- **关键元素**：
  - 标签详情含数据血缘（标签从哪些数据来）
  - 权重编辑器实时合计 + 模拟跑分
  - Knowhow 四层浏览
  - Skill Schema 展示

## 3. 信息架构原则

1. **企业视角优先**：前台默认按登录企业过滤，机会类数据（渗透/订单/机会标签）都带企业维度
2. **可解释优先**：每个分数/标签都能"下钻"到依据（雷达图、Top3、血缘、证据链）
3. **前台简洁、后台完整**：客户看结果，管理员管配置
4. **无外部依赖**：高保真原型均为自包含单页，双击可开
