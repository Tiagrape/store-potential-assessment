# 07 数据与算法设计

> 说明：本文档是产品视角的数据与算法设计（面向产品评审/研发评估），非完整实现。所有数值为示例占位，真实数据接入后校准。

## 1. 数据架构

```
ODS 原始层 → DWD 清洗层 → DIM 维表 → ads 汇总宽表 → 打分/标签/画像/推荐
```

### 明细数据域（ODS/DWD/DIM）
| 数据域 | 说明 | 关联键 |
| --- | --- | --- |
| 门店主数据 | 名称/地址/业态/面积/地理/渠道/状态 | `store_id` |
| 企业主数据 | 租户企业/行业/主营品类/品牌矩阵 | `tenant_enterprise_id` |
| 商品/品牌主数据 | SKU/品类/规格/价格带/品牌归属 | `product_id` / `brand_id` |
| 资产盘点 | POS/冷柜/货架/堆头/收银台 | `store_id` |
| 订单事实 | 订单头/明细/促销/退货 | `order_id` |
| 拜访事实 | 拜访时间/停留/目的/是否下单 | `visit_id` |
| 库存上报 | 在售SKU/库存量/排面/缺货/补货 | `inventory_report_id` |
| 竞品上报 | 竞品品牌/SKU/价格/陈列/促销 | `competitor_report_id` |
| 活动协议 | 合同/陈列/包柜/返利/有效期 | `agreement_id` |

### 统一宽表（`ads_tenant_store_rolling_metrics`）
企业-门店粒度，滚动窗口（30/90/180/365 天），字段分组：
- 主键/窗口、规模（gmv/订单/客单/SKU数）、活跃（销售天/断单/拜访）、渗透（品类数/份额/缺口）、库存（在售/缺货/周转）、竞争（竞品/促销/空白品类）、资源（冷柜/陈列/协议）

## 2. 打分模型

### 2.1 维度与权重（5 维，合计 100%）
| 维度 | 代码 | 权重 | 含义 |
| --- | --- | --- | --- |
| 基础盘面 | base | 15% | 业态/城市层级/面积/商圈 |
| 资产承载 | asset | 15% | 冷链/数字化/陈列/排面 |
| 交易表现 | performance | 30% | 成交规模/频次/活跃/品类/客单/促销健康（最重） |
| 竞争与机会 | opportunity | 25% | 竞品强度/渗透空白/份额上行/切入势能 |
| 触达可转化 | reachability | 15% | 拜访频次/转化/停留/冷启动 |

### 2.2 打分公式（二级指标示例）
| 指标 | 公式 | 说明 |
| --- | --- | --- |
| p_gmv 成交规模 | `logS(gmv; 100, 250000)` | 对数饱和，百元~25万元 |
| p_freq 订单频次 | `S(torders; 0, 60)` | 线性饱和 |
| p_act 活跃天数 | `S(tdays; 0, 40)` | 相对 90 天 |
| a_cold 冷链承载 | `S(cooler+0.5·freezer; 0, 5)` | 冷冻柜按 0.5 折算 |
| o_ws 渗透空白 | 渗透状态枚举 95/90/82/75/70/60 | 待开发最高 |

### 2.3 合成与修正
```
raw_score = Σ(维度分 × 权重)
risk_deduction = Σ(缺货-8 / 占压-5 / 断档-12 / 低转化-4 / 可信度-1)
final_score = clamp(raw_score − risk_deduction, 0, 100)
```

### 2.4 分位校准与分层
- **分位校准**：raw → 全库分位（单调、不改排序），让阈值落位合理
- **分层**：≥85 高潜 / 70-84 成长 / 50-69 基础 / <50 低效

### 2.5 校准（上线前提）
- 参数：K2 基准、公式上下限、分层阈值、风险系数、季节系数
- 方法：600 万门店分布统计（切桶分位）+ 历史成交回流验证 + 迭代
- 原则：只改参数，不改维度树/权重框架/合成公式

## 3. 标签体系

### 3.1 分层
| 层级 | 说明 | 例子 |
| --- | --- | --- |
| L1 原子 | 单字段/单规则 | 门店面积段、冷柜数量段 |
| L2 汇总 | 时间窗口聚合 | 近90天下单频次高 |
| L3 诊断 | 多指标解释 | 高流量低渗透门店 |
| L4 AI高阶 | AI 综合推理 | 高潜待激活门店 |

### 3.2 对象粒度
- 门店标签：`store_id`（跨企业一致）
- 企业-门店机会标签：`store_id + tenant_enterprise_id`（因企业而异）

### 3.3 AI 高阶标签（示例）
| 标签 | 主要输入 | 输出 |
| --- | --- | --- |
| 企业高潜待激活门店 | 面积/资产/竞品/拜访/库存/订单 | 高/中/低 |
| 企业竞品突破优先门店 | 竞品明细/自有品牌/价格带/拜访转化 | 可突破某品牌 |
| 企业流失高风险门店 | 断单/频次下滑/竞品上升 | 高风险 |
