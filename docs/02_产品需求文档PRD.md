# 02 产品需求文档（PRD）

> 版本：v1.0 ｜ 作者：产品经理 ｜ 状态：评审中
> 说明：本 PRD 面向"门店售卖潜力评估"产品。所有数值均为示例占位值，真实数据接入后校准（见 docs/07 与 10_待校准参数清单）。

## 1. 需求背景与目标

- **背景**：见 docs/01。
- **产品目标**：
  1. 识别每个企业对每家门店的售卖潜力（0-100 分 + 分层）
  2. 输出可解释的标签与画像，支撑"推给谁、推什么、怎么推"
  3. 覆盖管理：圈选高潜门店 → 推送企业 → 效果回溯

## 2. 用户角色

| 角色 | 说明 |
| --- | --- |
| 企业运营 | 查看本企业视角下的门店潜力与画像，圈选投放 |
| 销售/业务员 | 查看单店画像与推荐动作，准备拜访 |
| 平台管理员 | 治理标签、配置打分、预览任意企业视角、监控质量 |

## 4. 非功能需求

| 类别 | 需求 |
| --- | --- |
| 性能 | 列表秒级响应；600 万门店圈选分钟级 |
| 可解释性 | 每个分数可拆到维度→指标→证据字段 |
| 数据安全 | 企业视角隔离，客户仅见本企业数据 |
| 可复算 | 打分公式与参数配置化，可回溯 |
| 可回滚 | 参数版本化，支持回退 |

## 5. 数据需求

- 明细数据：订单、拜访、库存上报、竞品上报、活动协议、资产盘点（见 docs/07 §3）
- 汇总指标：企业-门店月度/年度/滚动窗口（规模、活跃、渗透、库存、竞争、资源）
- 打分输出：`ads_store_score` 落库表（final/五维/风险/证据链/置信度）

## 6. 指标定义（北极星 + 过程）

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| 高潜门店占比 | 潜力分≥85 门店数 / 全部门店 | 分层合理性（目标 ≤8%） |
| 误命中率 | 推送高潜店中 90 天未增购比例 | 推荐质量（目标 <8%） |
| 覆盖率提升 | 目标品牌成交门店数提升 | 产品价值 |
| 圈选 ROI | 可转化 GMV / 投入 | 投放决策 |

## 7. 版本规划

| 版本 | 范围 |
| --- | --- |
| MVP（当前原型） | 画像 + 后台 + 打分 Demo + 标签 Demo |

- 真实数据接入入口（待真数据到位）
- 预测型模型（PU Learning，后续升级）
