# 可交互高保真原型

两个原型均为**自包含单页**（数据内嵌 JS，无外部依赖），浏览器双击即可打开。

## 门店画像 v2（前台）
`04_门店画像_v2.html`
- 门店池列表 + 搜索筛选（城市层级/业态/潜力分层）
- 单店潜力分可视化：final/分层/分位/五维雷达图/Top3 驱动/风险扣分
- 企业视角概览、核心指标、AI 洞察、推荐动作、标签、竞品、库存资产、AI 提示词面板
- 分数拆解 explain（维度→指标→证据字段）

## 标签库管理后台 v2（后台）
`05_标签库管理后台_v2.html`
- ① 标签总览与分析：列表/筛选/详情（血缘/规则/审批/效果回溯）/覆盖预估与模拟圈选/质量监控
- ② 打分模型配置：维度权重编辑器/二级指标表/分层阈值/风险规则/**模拟跑分**
- ③ Knowhow 知识库：K1 口径/K2 基准/K3 场景/K4 动作
- ④ Skill 注册与调用：Schema/步骤/降级策略/运行记录

## 演示重点
- **模拟跑分**：后台 ② → 下拉选 S001 → 看 raw→校准→final→分层（与文档 07 一致）
- **权重可调**：把"交易表现"从 30% 拉到 10%，看分数变化（验证权重是配置，可调）

- 分数/权重/阈值为示例值，真实数据接入后校准
