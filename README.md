# 门店售卖潜力评估产品 · 产品实战作品集

> 面向 600 万门店 × 多租户经营数据的 **AI 售卖潜力评估产品**：把"某企业对某家门店的售卖潜力"算成可解释的分数与画像，把高潜门店推给企业，提升市场覆盖率。
> 本仓库是一套**完整的产品实战作品**：PRD、用户故事、信息架构、核心流程、数据与算法设计、两套可交互高保真原型、以及 ProcessOn 原型图/流程图/架构图。

## 🎯 项目亮点

- **企业-门店两层分析对象**：潜力不是"门店属性"，而是"某企业 × 某门店"这对关系
- **5 维潜力打分模型**：基础盘面/资产承载/交易表现/竞争机会/触达可转化（加权合成 + 分位校准 + 风险扣分）
- **Knowhow 行业知识库**：指标口径/基准阈值/场景模板/动作库四层，让打分与 AI 有据可依
- **Skill 标准化模块**：打分→标签→画像→推荐 流水线化，可复用、可自动化
- **两套可交互高保真原型**：自包含 HTML，浏览器直接打开即可操作
- **落地诚实**：所有数值标注为示例值，明确待真实数据校准的参数清单

## 🚀 快速体验

1. 浏览器打开 `prototype/04_门店画像_v2.html` → 看单店潜力画像（潜力分、雷达图、Top3 驱动、风险扣分、三级拆解）
2. 浏览器打开 `prototype/05_标签库管理后台_v2.html` → 看标签治理 + 打分模型配置 + Knowhow + Skill

4. `docs/06_原型说明与使用指南.md` 有完整演示顺序
