# ProcessOn 使用说明（导入 → 微调 → 导出）

本作品集的 7 张图（原型线框图 / 流程图 / 架构图）以 **draw.io XML** 源文件形式存放在 `design/` 下。
由于 **ProcessOn 支持直接导入 draw.io 文件**，你无需重新画图，导入即可查看、微调、导出 PNG。

## 一、导入到 ProcessOn

1. 打开 ProcessOn 官网：**https://www.processon.com**（国内免费，注册/登录）
2. 进入个人文件页，点「**新建**」→「**导入**」（或右上角「上传」）
3. 选择 `design/` 下的 `.drawio` 文件，例如 `原型线框图/门店画像-线框图.drawio`
4. ProcessOn 会解析并打开该图（作为流程图/原型图类型的文件）

> 若导入后提示格式兼容问题：drawio 的 `.drawio` 是标准 `mxGraphModel` XML，ProcessOn 支持度高；如个别样式（如填充色）显示有差异，可在 ProcessOn 里手动微调。

## 二、在 ProcessOn 里微调

- **改文字**：双击文本框编辑
- **改布局**：拖拽节点；连线自动吸附
- **改样式**：选中节点 → 右侧「样式」面板改填充色/边框/字体
- **加图例/说明**：用「T」文本框补充

## 三、导出为 PNG（简历用）

1. 打开该图 → 顶部菜单「**导出**」→「**PNG**」（或「图片」）
2. 选择分辨率（建议 ≥2x，够清晰）
3. 保存到本仓库的 `assets/` 目录（如 `assets/门店画像-线框图.png`）
